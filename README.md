# Video-Game-Library

Presents video games in a compact and digestible way. Allows for easy access without jumping to multiple different platforms.  
Uses the IDGB API to fetch the data : https://api-docs.igdb.com/#getting-started  
To see live web (shows early draft to give good idea for now): https://video-game-library-iy6w.onrender.com  
Living project, i.e. I add cool features now and then
