# Video-Game-Library

Presents video games in a compact and digestible way. Allows for easy access in an all-in-one systems, with some fun features included.  
Uses the IDGB API to fetch the data : https://api-docs.igdb.com/#getting-started  
Live web: https://video-game-library-iy6w.onrender.com  
Note - Safari formats it weirdly so it looks smaller (the images on the home page) than it should. Google Chrome is where I mainly tested how it looked :)
